================================================================================
✨ ÖZELLİKLER
================================================================================

KANAL TAHMİNİ (Channel Estimation):
  ✓ İki LTS ortalaması ile kanal katsayıları
  ✓ Smoothing (DC ve LTS bölgeleri)
  ✓ CSI (Channel State Information) çıkışı
  ✓ Legacy ve HT modu desteği

FAZ HATASI DÜZELTMESİ:
  ✓ CPE (Common Phase Error): RFO kompanzasyonu
  ✓ LVPE (Linear Varying Phase Error): SFO düzeltmesi
  ✓ 4 pilot alt-taşıyıcı ile tracking
  ✓ Phase error gradient hesabı

KANAL EŞİTLEME (Equalization):
  ✓ Zero-forcing (Y/H) eşitleme
  ✓ Phase rotation (LUT tabanlı)
  ✓ Complex multiplication & division
  ✓ 48/52 veri alt-taşıyıcı çıkışı

FIXED-POINT:
  ✓ Input/Output: int16 (signed 16-bit)
  ✓ İç hesaplamalar: int32 (signed 32-bit)
  ✓ Phase: int16 (-π to π, scaled by 512)
  ✓ Rotation LUT: 512 entry, scale 2048

================================================================================
📐 FIXED-POINT FORMATLAR
================================================================================

Değişken               | Format | Açıklama
-----------------------|--------|----------------------------------
Input/Output Samples   | int16  | Signed 16-bit integer
LTS Buffer             | int16  | Channel coefficients
Pilot Accumulator      | int32  | 32-bit signed accumulator
Phase (CPE)            | int16  | -π to π, scaled by 512
Phase Error (LVPE)     | int32  | Phase error gradient
Rotation LUT           | int16  | 512 entries, scale 2048
Magnitude Squared      | int32  | For normalization
