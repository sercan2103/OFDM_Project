💡 ÖNEMLİ NOTLAR:
----------------

✓ FIXED-POINT: Tüm girişler int16 tipinde olmalı (Q15 format)
  Örnek: lts1_i = int16(randn(64,1) * 5000);

✓ LTS UZUNLUĞU: Genellikle 64 örnek (IEEE 802.11a/g/n)
  LTS1 ve LTS2 aynı uzunlukta olmalı

✓ SIGN VEKTÖRÜ: LTS referans sekansından gelir
  sign_vec = (lts_freq == -1)'

✓ PIPELINE DELAY: İlk 2-3 çıkış invalid olacaktır
  np_valid ve m_valid çıkışlarını kontrol edin

✓ VERILOG UYUMLULUĞU: Bu kod, calc_mean.v modülünün birebir kopyasıdır
  Bit-exact sonuçlar verir

📊 TEMEL KULLANIM ÖRNEĞİ:
-------------------------

% 64 LTS örneği oluştur
N = 64;
lts1_i = int16(randn(N,1) * 5000);
lts1_q = int16(randn(N,1) * 5000);
lts2_i = lts1_i + int16(randn(N,1) * 500);  % + gürültü
lts2_q = lts1_q + int16(randn(N,1) * 500);
sign_vec = zeros(N, 1);

% Fonksiyonu çağır
[noise_power, np_valid, mean_i, mean_q, m_valid] = ...
    noise_power_estimator(lts1_i, lts1_q, lts2_i, lts2_q, sign_vec, 1);

% Ortalama gürültü gücü
avg_noise_power = mean(double(noise_power(np_valid)));
fprintf('Ortalama Gürültü Gücü: %.2f\n', avg_noise_power);

🆘 SORUN GİDERME:
-----------------

Problem: "lts1_i int16 tipinde olmalı" hatası
Çözüm: lts1_i = int16(lts1_i);

Problem: Noise power çok yüksek/düşük
Çözüm: Girişleri [-32768, 32767] aralığına ölçekleyin

Problem: Valid çıkışları yok
Çözüm: clk_enable = 1 olmalı, N >= 3 olmalı
